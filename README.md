# CONCAPAN XLIV 2026 program

A mobile-friendly companion schedule for the 2026 IEEE 44th Central America and Panama Convention (CONCAPAN XLIV).

**Live site:** https://jaime-sql.github.io/concapan-2026-program/

Times are in America/Guatemala (UTC-6, same as El Salvador). Venue: Hotel Westin Camino Real, Ciudad de Guatemala. Dates: 10–13 November 2026.

This is an unofficial companion. Session titles are kept as published. The official program is at [attend.ieee.org/concapan-2026/en/program](https://attend.ieee.org/concapan-2026/en/program/).

The full calendar is in [`CONCAPAN-2026-program.ics`](CONCAPAN-2026-program.ics) (101 events). Structured data is in [`data/program.json`](data/program.json) (101 sessions, 107 papers).
